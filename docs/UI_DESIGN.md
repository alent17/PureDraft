# PureDraft UI 设计文档

本文档全面描述 PureDraft 桌面 Markdown 编辑器的用户界面设计，包括布局架构、组件系统、交互模式和视觉规范。

---

## 1. 产品概述

### 1.1 产品定位

PureDraft 是一款极简、丝滑的桌面 Markdown 编辑器，基于 Tauri 2 构建，追求**内容优先**的编辑体验。以 Neo-Brutalism 与 Tech-wear 设计美学为视觉基调，配合 120Hz 丝滑动画与物理弹簧反馈，让写作本身成为一种享受。

### 1.2 核心功能

- **实时 Markdown 预览** — 所见即所得的分屏编辑模式
- **多视图模式** — 纯编辑、纯预览、分屏三种模式自由切换
- **代码高亮** — 支持 20+ 编程语言的语法高亮
- **数学公式** — 基于 KaTeX 的 LaTeX 公式渲染
- **Mermaid 图表** — 内置 Mermaid 图表渲染支持
- **文件管理** — 内置文件树、多标签页、自动保存、存档管理
- **个性化** — 深色/浅色主题、多主题色、自定义字体、编辑器缩略图

### 1.3 技术栈

| 层级 | 技术 |
|------|------|
| 桌面框架 | Tauri 2 |
| 后端语言 | Rust |
| 前端框架 | Svelte 5 (Runes) |
| 编辑器 | CodeMirror 6 |
| 构建工具 | Vite |
| Markdown 解析 | marked |
| 代码高亮 | highlight.js |
| 数学公式 | KaTeX |
| 图表 | Mermaid |

## 2. 整体布局架构

### 2.1 布局结构

PureDraft 采用经典的 IDE 布局模式，垂直方向分为四个主要区域：

```
┌─────────────────────────────────────────────────────────────┐
│                      TitleBar (32px)                         │
├─────────────────────────────────────────────────────────────┤
│                      Toolbar (36px)                          │
├──────────────┬──────────────────────────────────────────────┤
│              │           TabBar (34px)                       │
│              ├──────────────────────────────────────────────┤
│   Sidebar    │        ViewTabBar (36px)                      │
│   (240px)    ├──────────────────────────────────────────────┤
│              │                                               │
│              │          Editor / Preview Area                │
│              │                                               │
│              │                                               │
│              │                                               │
│              │                                               │
├──────────────┴──────────────────────────────────────────────┤
│                     StatusBar (26px)                         │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 区域尺寸规范

| 区域 | 高度/宽度 | CSS 变量 | 说明 |
|------|-----------|----------|------|
| 标题栏 | 32px | `--titlebar-height` | 固定高度，可拖拽区域 |
| 工具栏 | 36px | `--toolbar-height` | 固定高度，可隐藏 |
| 文件标签栏 | 34px | — | 显示已打开文件列表 |
| 视图切换栏 | 36px | `--tabbar-height` | Editor/Preview/Split 切换 |
| 侧边栏 | 240px | — | 可折叠，范围 180-360px |
| 状态栏 | 26px | `--statusbar-height` | 固定高度 |
| 编辑区 | 自适应 | — | 填充剩余空间 |

### 2.3 响应式断点

| 断点 | 宽度 | 行为 |
|------|------|------|
| 小 | < 640px | 移动设备适配 |
| 中 | 640px - 1024px | 平板模式 |
| 大 | > 1024px | 桌面模式（默认） |

## 3. 组件系统

### 3.1 组件层级关系

```
App.svelte
├── TitleBar
│   ├── Logo (PD)
│   ├── FileName Display
│   └── Window Controls (最小化/最大化/关闭)
├── Toolbar
│   ├── File Operations (打开/新建/保存/另存为)
│   ├── Export Tools (导出HTML/打印)
│   └── App Tools (侧边栏/主题/存档/设置)
├── MainArea
│   ├── FileTree (Sidebar)
│   │   ├── SidebarTabs (大纲/文件)
│   │   ├── Outline
│   │   └── RecentFiles
│   └── ContentArea
│       ├── FileTabs (文件标签)
│       ├── ViewTabBar
│       │   ├── Editor Tab
│       │   ├── Preview Tab
│       │   └── Split Tab
│       ├── MDToolbar (Markdown 工具栏)
│       └── EditorPreviewArea
│           ├── Editor (CodeMirror 6)
│           ├── Preview (Markdown 渲染)
│           ├── HoverPreview (悬浮预览)
│           └── Minimap (缩略图)
├── StatusBar
│   ├── FileInfo (文件类型/同步状态)

│   ├── ConfirmDialog

    ├── DragOverlay (拖拽提示)
    └── FormatToast (格式化提示)
```

### 3.2 核心组件详解

#### 3.2.1 TitleBar 组件

**位置**: 窗口顶部  
**高度**: 32px  
**功能**: 显示应用标识、当前文件名、窗口控制按钮

**布局结构**:
```
┌─────────────────────────────────────────────────────────────┐
│ [PD]          ● filename.md              ─ □ ✕            │
└─────────────────────────────────────────────────────────────┘
```

**交互特性**:
- 整个区域可拖拽移动窗口
- 双击标题栏切换最大化/还原
- 文件名前显示修改状态指示器 (●)
- 文件名超长时显示省略号，hover 显示完整路径
- 关闭按钮 hover 时显示红色背景 (#E81123)

**状态变量**:
- `fileName`: 当前文件名（含修改状态前缀）
- `max`: 最大化状态

#### 3.2.2 Toolbar 组件

**位置**: 标题栏下方  
**高度**: 36px  
**功能**: 提供常用操作的快捷访问

**布局结构**:
```
┌─────────────────────────────────────────────────────────────┐
│ [打开][新建][保存][另存为] | [导出HTML][打印] | [侧边栏][主题][存档][设置] │
└─────────────────────────────────────────────────────────────┘
```

**按钮分组**:
1. **文件操作组**: 打开、新建、保存、另存为
2. **导出组**: 导出 HTML、打印
3. **应用工具组**: 侧边栏切换、主题切换、存档管理、设置

**交互特性**:
- 所有按钮禁用状态降低透明度 (0.35)
- 按钮 hover 显示背景色变化
- 分组间使用竖线分隔符
- 主题切换按钮根据当前模式显示不同图标

#### 3.2.3 FileTree (侧边栏) 组件

**位置**: 主区域左侧  
**宽度**: 240px（可折叠）  
**功能**: 文件导航和大纲视图

**布局结构**:
```
┌─────────────────────┐
│ [大纲] [文件]        │
├─────────────────────┤
│ 常用                 │
│  ┌─────────────────┐│
│  │ 📄 document.md  ││
│  │ 📄 script.js    ││
│  └─────────────────┘│
│ 最近文件             │
│  ┌─────────────────┐│
│  │ 📘 types.ts     ││
│  │ 🌐 index.html   ││
│  └─────────────────┘│
└─────────────────────┘
```

**标签页**:
1. **大纲 (Outline)**: 显示当前文件的标题结构
2. **文件 (Files)**: 显示常用和最近文件列表

**文件项特性**:
- 显示文件图标（根据文件类型着色）
- 文件名超长时显示省略号
- Hover 时显示操作菜单按钮 (...)
- 支持固定/取消固定文件
- 支持重命名和删除操作
- 删除操作有二次确认

**动画效果**:
- 文件项进入动画: `translateX(-12px)` → `translateX(0)`
- Hover 效果: 上移 1px + 阴影
- 点击效果: 缩放 0.98

#### 3.2.4 TabBar (文件标签栏) 组件

**位置**: 内容区域顶部  
**高度**: 34px  
**功能**: 显示已打开的文件列表

**布局结构**:
```
┌─────────────────────────────────────────────────────────────┐
│ [● document.md ✕] [script.js ✕] [types.ts ✕]              │
└─────────────────────────────────────────────────────────────┘
```

**标签特性**:
- 活动标签底部有 2px 强调色指示条
- 修改文件显示修改指示点 (●)
- 关闭按钮默认隐藏，hover 时显示
- 标签超长时显示省略号
- 支持标签滚动（水平溢出时）

**关闭确认**:
- 未保存文件关闭时弹出确认对话框
- 确认文本: "关闭"/"取消"

#### 3.2.5 ViewTabBar (视图切换栏) 组件

**位置**: 文件标签栏下方  
**高度**: 36px  
**功能**: 切换编辑器视图模式

**布局结构**:
```
┌─────────────────────────────────────────────────────────────┐
│ [✏️ Editor] [👁️ Preview] [⬜ Split]        [⇄] [□]         │
└─────────────────────────────────────────────────────────────┘
```

**视图模式**:
1. **Editor**: 纯编辑模式
2. **Preview**: 纯预览模式（仅 Markdown 文件可用）
3. **Split**: 分屏模式（仅 Markdown 文件可用）

**右侧操作按钮**:
- **滚动同步** (⇄): 同步编辑器和预览的滚动位置
- **悬浮预览** (□): 在编辑模式下显示悬浮预览窗口

**交互特性**:
- 活动标签底部有 2px 强调色指示条
- 启用状态按钮显示强调色

#### 3.2.6 MDToolbar (Markdown 工具栏) 组件

**位置**: 视图切换栏下方  
**高度**: 36px  
**功能**: 提供 Markdown 格式化快捷操作

**布局结构**:
```
┌─────────────────────────────────────────────────────────────┐
│ [全选] | [H1][H2][H3] | [B][I][S][Code] | [Link][Img][Quote] | [UL][OL][Task] | [Table][CodeBlock][HR] | [LaTeX][Block][Mermaid] │
└─────────────────────────────────────────────────────────────┘
```

**工具分组**:
1. **通用工具**: 全选相同文本
2. **标题工具**: 一级、二级、三级标题
3. **文本格式**: 粗体、斜体、删除线、行内代码
4. **插入工具**: 链接、图片、引用块
5. **列表工具**: 无序列表、有序列表、待办任务
6. **块级元素**: 表格、代码块、分割线
7. **高级元素**: 行内公式、块级公式、Mermaid 图表

**交互特性**:
- 点击按钮在光标位置插入对应 Markdown 语法
- 有选中文本时自动包裹
- 非 Markdown 文件时仅显示"全选"按钮

#### 3.2.7 Editor (编辑器) 组件

**位置**: 内容区域主区域  
**功能**: CodeMirror 6 代码编辑器

**核心特性**:
- 基于 CodeMirror 6 构建
- 支持 20+ 编程语言语法高亮
- 行号显示
- 代码折叠
- 搜索替换 (Ctrl+F)
- 多光标编辑
- 自动缩进
- 括号匹配
- 活动行高亮

**主题配置**:
- 深色模式: 深色背景 (#1F1F1F) + 浅色文字 (#D4D4D4)
- 浅色模式: 白色背景 (#FFFFFF) + 深色文字 (#171717)
- 光标颜色跟随强调色
- 选区背景半透明强调色

**Minimap 显示条件**:
- 文件超过 50 行时自动显示
- 宽度 80px，位于编辑器右侧
- 显示代码缩略图和当前视口位置

#### 3.2.8 Preview (预览) 组件

**位置**: 内容区域（预览/分屏模式）  
**功能**: Markdown 实时渲染预览

**渲染特性**:
- 使用 marked 解析 Markdown
- DOMPurify 净化 HTML
- highlight.js 代码高亮
- KaTeX 数学公式渲染
- Mermaid 图表渲染
- 任务列表支持勾选操作

**交互特性**:
- 任务列表点击可切换完成状态
- 搜索功能（Ctrl+F）
- 滚动同步支持

#### 3.2.9 HoverPreview (悬浮预览) 组件

**位置**: 编辑器右侧浮动  
**尺寸**: 360px × 300px  
**功能**: 编辑模式下的实时预览窗口

**布局结构**:
```
┌─────────────────────────────┐
│ 实时预览              [✕]   │
├─────────────────────────────┤
│                             │
│   Markdown 渲染内容         │
│                             │
│                             │
└─────────────────────────────┘
```

**交互特性**:
- 可拖拽移动位置
- 默认透明度 0.65，hover/拖拽时 1.0
- 支持滚动同步
- 代码块显示语言标签
- 可通过 Ctrl+Shift+H 切换显示

#### 3.2.10 StatusBar (状态栏) 组件

**位置**: 窗口底部  
**高度**: 26px  
**功能**: 显示文件信息和编辑器状态

**布局结构**:
```
┌─────────────────────────────────────────────────────────────┐
│ Markdown | ○ 同步就绪 | 自动保存 30s   字数 1234 | 约 5min  │
│     🌙 Dark | UTF-8 | Ln 12, Col 5 | 45.2 KB              │
└─────────────────────────────────────────────────────────────┘
```

**信息分组**:
1. **左侧**: 文件类型、同步状态、自动保存间隔
2. **中部**: 字数统计（选中字数/总字数）、阅读时间
3. **右侧**: 主题模式、编码格式、光标位置、文件大小

**同步状态指示**:
- `○ 同步就绪`: 正常状态
- `◉ 同步中`: 脉冲动画
- `⨯ 同步异常`: 红色文字

**字数统计动画**:
- 使用 AnimatedNumber 组件实现数字变化动画
- 选中文本时显示"选中 X 字 · 总 Y 字"

## 4. 视图模式

### 4.1 编辑模式 (Editor)

**适用文件**: 所有文件类型  
**布局**: 单栏编辑器

```
┌─────────────────────────────────────────┐
│                                         │
│              CodeMirror                 │
│              编辑器                      │
│                                         │
│                                         │
│                                         │
└─────────────────────────────────────────┘
```

**特性**:
- 全屏编辑区域
- 行号显示
- 代码折叠
- 搜索替换
- Minimap（文件 > 50 行时）

### 4.2 预览模式 (Preview)

**适用文件**: Markdown 文件  
**布局**: 单栏预览

```
┌─────────────────────────────────────────┐
│                                         │
│              Markdown                   │
│              渲染预览                    │
│                                         │
│                                         │
│                                         │
└─────────────────────────────────────────┘
```

**特性**:
- 实时 Markdown 渲染
- 代码高亮
- 数学公式
- Mermaid 图表
- 任务列表可勾选

### 4.3 分屏模式 (Split)

**适用文件**: Markdown 文件  
**布局**: 左右分栏，可拖拽分割线

```
┌───────────────────┬───────────────────┐
│                   │                   │
│    CodeMirror     │    Markdown       │
│    编辑器         │    渲染预览       │
│                   │                   │
│                   │                   │
│                   │                   │
└───────────────────┴───────────────────┘
```

**特性**:
- 分割线可拖拽调整比例（20%-80%）
- 默认 50% 分割
- 滚动同步支持
- 窗口宽度 < 900px 时自动切换为上下布局

### 4.4 专注模式 (Focus Mode)

**触发方式**: Ctrl+Shift+F  
**布局**: 居中编辑区域，隐藏所有 UI 元素

```
┌─────────────────────────────────────────┐
│                                         │
│                                         │
│         ┌─────────────────────┐         │
│         │                     │         │
│         │      Editor         │         │
│         │                     │         │
│         └─────────────────────┘         │
│                                         │
│                                         │
└─────────────────────────────────────────┘
```

**特性**:
- 隐藏标题栏、工具栏、侧边栏、标签栏、状态栏
- 编辑区域最大宽度 860px，居中显示
- 上下内边距 60px，左右 40px
- Escape 键退出

### 4.5 悬浮预览模式

**触发方式**: Ctrl+Shift+H 或视图切换栏按钮  
**适用场景**: 编辑模式下查看 Markdown 预览

```
┌─────────────────────────────────────────┐
│                                         │
│              Editor                     │
│                                         │
│                    ┌──────────────────┐ │
│                    │ 实时预览    [✕]  │ │
│                    │                  │ │
│                    │ Preview Content  │ │
│                    └──────────────────┘ │
└─────────────────────────────────────────┘
```

**特性**:
- 固定尺寸 360px × 300px
- 可拖拽移动位置
- 默认透明度 0.65，交互时 1.0
- 支持滚动同步

## 5. 交互模式

### 5.1 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+O | 打开文件 |
| Ctrl+S | 保存 & 格式化 |
| Ctrl+Shift+S | 另存为 |
| Ctrl+N | 新建文件 |
| Ctrl+B | 切换侧边栏 |
| Ctrl+Shift+F | 专注模式 |
| Ctrl+Shift+H | 悬浮预览 |
| Escape | 退出专注模式/关闭对话框 |

### 5.2 拖拽交互

**文件拖拽**:
- 支持拖拽文件到窗口打开
- 拖拽时显示虚线边框提示
- 支持多文件同时拖拽
- 自动识别文件类型

**分割线拖拽**:
- 分屏模式下可拖拽分割线
- 拖拽范围限制在 20%-80%
- 拖拽时禁用文本选择
- 显示拖拽光标 (col-resize)

**悬浮预览拖拽**:
- 可拖拽移动位置
- 位置限制在窗口范围内
- 拖拽时提高透明度

### 5.3 滚动同步

**同步对象**:
- 编辑器 ↔ 预览
- 编辑器 ↔ 悬浮预览
- 预览 ↔ 悬浮预览

**同步算法**:
- 基于滚动比例的同步
- 节流控制 (30ms)
- 防止循环同步
- 同步状态指示器

### 5.4 自动保存

**触发条件**:
- 用户可配置间隔：关闭/10s/30s/1min/2min
- 仅保存已修改且有路径的文件

**保存流程**:
1. 检查文件是否已修改
2. 格式化内容（如适用）
3. 保存到文件系统
4. 创建自动存档

### 5.5 文件关联

**功能**: 将 PureDraft 设为 .md 文件的系统默认打开程序

**状态显示**:
- 已是默认：绿色标签 "已是默认"
- 未设置：蓝色按钮 "设为默认"
- 设置中：按钮显示 "设置中..."

## 6. 动画系统

### 6.1 动画时长

| 类型 | 时长 | 用途 |
|------|------|------|
| 快速 | 100ms | 按钮悬停、颜色变化 |
| 标准 | 150ms | 面板展开、下拉菜单 |
| 中等 | 200ms | 对话框、模态框 |
| 慢速 | 300ms | 主题切换、大动画 |

### 6.2 缓动函数

```css
/* 标准缓动 */
--ease-out: cubic-bezier(0.4, 0, 0.2, 1);
--ease-in-out: cubic-bezier(0.4, 0, 0.2, 1);

/* 弹性缓动 */
--ease-bounce: cubic-bezier(0.2, 0.8, 0.2, 1);
```

### 6.3 常用动画

**淡入 (fadeIn)**:
```css
@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}
```

**上滑淡入 (slideUp)**:
```css
@keyframes slideUp {
  from { opacity: 0; transform: translateY(20px) scale(0.98); }
  to { opacity: 1; transform: translateY(0) scale(1); }
}
```

**缩放淡入 (scaleIn)**:
```css
@keyframes scaleIn {
  from { opacity: 0; transform: scale(0.95); }
  to { opacity: 1; transform: scale(1); }
}
```

**下拉菜单进入 (dropdownIn)**:
```css
@keyframes dropdownIn {
  from { opacity: 0; transform: scale(0.95) translateY(-4px); }
  to { opacity: 1; transform: scale(1) translateY(0); }
}
```

**文件项进入 (fileItemIn)**:
```css
@keyframes fileItemIn {
  from { opacity: 0; transform: translateX(-12px); }
  to { opacity: 1; transform: translateX(0); }
}
```

**同步脉冲 (sync-pulse)**:
```css
@keyframes sync-pulse {
  0%, 100% { opacity: 1; }
  50% { opacity: 0.4; }
}
```

## 8. 无障碍设计

### 8.1 对比度要求

- 正文文字对比度 ≥ 4.5:1
- 大文字对比度 ≥ 3:1
- 交互元素对比度 ≥ 3:1

### 8.2 焦点状态

```css
:focus-visible {
  outline: 2px solid var(--color-accent);
  outline-offset: 2px;
}
```

### 8.3 交互反馈

- 所有可点击元素必须有 hover 状态
- 按钮点击应有 active 状态（缩放或颜色变化）
- 禁用状态应有视觉提示（降低透明度）

### 8.4 ARIA 属性

- 对话框使用 `role="dialog"` 和 `aria-modal="true"`
- 按钮使用 `aria-label` 描述功能
- 使用 `tabindex` 管理焦点顺序
